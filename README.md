# 国际会议同声传译和发言队列控制

源提示词摘要：主持人维护代表发言队列、剩余时间、议题和临时插话；翻译团队维护多语种频道、术语和译员交接；字幕人员修正实时文本。队列调整保留版本，发言者切换后旧译文不会误绑定，并提供低延迟大屏模式和多会议厅隔离。

## 技术栈

Qwik City、TypeScript、Qwik UI、Qwik stores、TanStack Query、Modular Forms、Zod、qwik-speak。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62029`

## 可用流程

- 多会议厅独立维护代表、议题和发言队列，切换厅时数据互不影响。
- 发言人从排队、发言中、完成到跳过，支持临时插话和剩余时间调整。
- 多语种频道维护译员、术语和交接；交接后新增字幕归属新译员。
- 实时字幕支持版本化修正，低延迟模式只保留关键状态并停用非必要动态。
- 数据保存在浏览器 localStorage，刷新后继续保留。

## 接力链控制台（/relay）

小语种无直译时，发言按「源语言 → 中间语言（常为英语）→ 目标语言」逐段接力：

- **确认门控**：每条发言段同时建源/中间/目标三段，标明三种语言；中间段只有草稿不算数，未确认前目标段为 blocked，下游大屏不出字幕；中间确认才放行目标岗，目标确认才拍快照播出。
- **发言变更即时失效**：源文修订（段级）或整条换稿会抬升 sourceRev，对应中间段、目标段立即转 stale 并清空 airedText——旧字幕当场停播，必须按新版本逐段重算；草稿带 basedOnVersion，过期版本不允许确认。
- **断点恢复不重放**：频道掉线/换人在该环节「第一个未确认段」落断点，已确认段 frozen 保留（字幕继续在播）；恢复时仅把 recovering 段退回 pending 补译，冻结段绝不整条重放。换人后新译文归属新译员，旧段归属不变。
- 纯状态机逻辑在 `src/relay/relay-chain.ts`（框架无关），控制台在 `src/routes/relay/index.tsx`，事件时间线完整记录确认、失效、中断与恢复。
